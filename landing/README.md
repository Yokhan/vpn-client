# Yokhan Client Landing

Standalone client-facing landing/onboarding page.

Open directly:

```text
landing/index.html
```

No build tools or external dependencies are required.

Purpose:

- explain the private invite-only setup;
- prepare the invited person, family helper, friend helper, or small-team owner before installation;
- make support messages copyable;
- keep copy calm, clear, and honest;
- reuse the app design-system assets from `shared/ui`: rocket, flame, Unbounded, Golos Text, and JetBrains Mono.
