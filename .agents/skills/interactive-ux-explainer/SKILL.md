# Interactive UX Explainer

Every visual affordance must keep its promise.

Useful patterns:

- Scenario selector.
- Decision matrix.
- Readiness checker.
- Progress checklist.
- Copyable messages.
- Glossary/details.
- Sticky verdict.

QA:

- Click every button-looking element.
- Verify active, hover, focus, and copied states.
- Test mobile width and keyboard navigation.
- Restyle any non-clickable decoration so it does not look interactive.
