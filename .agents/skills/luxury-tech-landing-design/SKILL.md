# Luxury Tech Landing Design

Visual direction:

- Dark editorial.
- Calm premium surfaces.
- Strong typography.
- Subtle gradients and glow.
- Technical instrument feel.
- Low visual noise.

Default palette:

```css
--bg: #090908;
--panel: rgba(17,17,16,.78);
--panel-soft: rgba(255,255,255,.035);
--line: rgba(255,255,255,.10);
--text: #f7f2e8;
--muted: #b8b0a3;
--faint: #7b756c;
--gold: #f6d88a;
--green: #a7f3d0;
--red: #fecaca;
```

Avoid neon cyberpunk, noisy borders, tiny grey text, and decorative controls.
