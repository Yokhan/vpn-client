# Beginner Explainer Layer

Do not simplify by deleting important detail. Add orientation.

Required for technical pages:

- Fast path for non-experts.
- Glossary.
- Practical checklists.
- Stop conditions.
- Copyable messages.
- Expected result examples.

Glossary format:

- What it is.
- Why it matters.
- How to check or act.
