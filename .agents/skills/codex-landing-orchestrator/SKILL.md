# Codex Landing Orchestrator

Use first for landing, onboarding, commercial page, decision guide, or web explainer tasks.

Workflow:

1. Distill the user goal, audience, decision, warnings, actions, and forbidden UI copy.
2. Design the decision flow: verdict, fast path, scenario selector, matrix, cards, checklist, glossary, templates, final action.
3. Rewrite copy in clear Russian. Remove assistant/chat artifacts.
4. Implement as standalone HTML by default.
5. Verify interactions, mobile layout, keyboard focus, copy buttons, console, and forbidden text.

For this project:

- Make landing pages useful for private invite-only onboarding and support.
- Do not disguise network functionality as an unrelated game.
- Use rocket metaphors only as visual language.
- Keep private distribution and provider installation explicit.
