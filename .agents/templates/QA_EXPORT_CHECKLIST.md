# QA Export Checklist

## File

- [ ] `index.html` exists.
- [ ] Opens directly in a browser.
- [ ] No npm/build required.
- [ ] No unintended external dependencies.

## Console

- [ ] No JS errors.
- [ ] No missing assets.
- [ ] No blocked resources.

## Interaction

- [ ] Scenario controls work.
- [ ] Cards/filters work.
- [ ] Checker updates.
- [ ] Checklist progress updates.
- [ ] Copy buttons work.
- [ ] Glossary opens.
- [ ] Reset works if present.

## Content

- [ ] No assistant meta-text.
- [ ] No lorem ipsum.
- [ ] No unexplained scores.
- [ ] No fake buttons.
- [ ] No promises without implementation.

## Mobile And A11y

- [ ] 390px width works.
- [ ] No accidental horizontal scroll.
- [ ] Focus states visible.
- [ ] Buttons are real buttons.
