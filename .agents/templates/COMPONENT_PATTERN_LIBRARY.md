# Component Pattern Library

## Verdict Card

- Title.
- One sentence decision.
- Conditions.
- Primary action.

## Scenario Selector

- 3 to 5 real scenarios.
- Active state.
- Updates recommendation text.

## Decision Matrix

- Criteria.
- Qualitative rating.
- Explanation.
- Mobile-safe layout.

## Readiness Checklist

- Checkboxes.
- Progress.
- Final verdict.
- Stop conditions.

## Copyable Template

- Short context.
- Message body.
- Copy button with copied state.
